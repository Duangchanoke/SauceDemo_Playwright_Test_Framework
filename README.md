SauceDemo Playwright Test Framework

A TypeScript-based end-to-end test automation framework built with Playwright, demonstrating how to use the Page Object Model (POM) design pattern to create maintainable, reusable, and scalable automated test scenarios for the SauceDemo website.

Project Objectives
1. Automate end-to-end user workflows on the SauceDemo website.
2. Demonstrate the Page Object Model design pattern.
3. Use TypeScript for strongly typed and maintainable test code.
4. Separate test scenarios from page-specific locators and actions.
5. Create reusable page objects and test utilities.
6. Generate Playwright test reports and debugging artifacts.

Technology Stack
1. Playwright – End-to-End Automation Testing
2. TypeScript – Programming Language
3. Node.js – Runtime Environment
4. Page Object Model – Test Design Pattern
5. Playwright Test – Test Runner and Reporting

Example Test Scenarios:
- Login with valid credentials.
- Login with invalid credentials.
- Verify the list of all available products.
- Sort all products by name and price.
- Add selected products to the shopping cart.
- Verify the shopping cart's details.
- Complete the checkout process.
- Verify the order confirmation.
- Logout successfully.
